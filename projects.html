PRJ_01 // WEB APP

GUTECH Portal: Learning Management System

A student and faculty portal with three roles (admin, teacher, student). It is a closed system, so accounts are created by an administrator. Built full-stack and deployed on Vercel with a Supabase backend.

  • Courses, resources, assignments and timed quizzes with server-side scoring
  • Gradebook with CSV export, plus bulk CSV import of users
  • Announcements, complaints and realtime course chat
  • Row Level Security on every table. Deadlines and quiz timers use the database clock
  • Role-based route protection, password reset by email and login rate limiting
Next.js 16 React 19 TypeScript Tailwind CSS v4 Supabase PostgreSQL Vercel
Live site GitHub repo
PRJ_02 // WEB APP (PWA)

Sukoon (سكون): Digital Well-Being App

Sukoon means calm. It is a private, mobile-first well-being web app for university students, built for a Digital Well-Being and Mental Health midterm. It installs like an app and keeps working offline.

  • Pause check-in, focus sessions and a night wind-down flow
  • Study tab: Pomodoro, weekly goals, spaced-repetition flashcards and a focus garden that never wilts
  • Optional accounts with cross-device sync. Mood notes stay private unless the student opts in
  • Anonymous, moderated community circles, plus push-notification reminders
  • Automated tests for the API, accounts, reminders and browser flows
HTML / CSS / JavaScript PWA Vercel Functions Supabase Web Push
Live site GitHub repo
PRJ_03 // WEB APP

Doctor and Pharmacy Linked Web App

A design thinking prototype for the Karachi Institute of Heart Diseases. A doctor console and a pharmacy/lab app share one Supabase database, so a prescription sent by a doctor shows up in the pharmacy queue within seconds.

  • Dispensing deducts stock atomically, and the doctor sees the prescription marked Dispensed
  • Dose builder: dose, times a day and days calculate the quantity automatically
  • Alternatives search lists other brands with the same formula, flagged same or different strength
  • Role-based logins: a doctor sees only their own prescriptions, pharmacy sees all
Node.js Serverless API Supabase PostgreSQL JavaScript Vercel
Live site GitHub repo

PRJ_05 // COMPETITION ROBOT

Line Following Robot

An autonomous line following robot of the kind used in robotics competitions such as Robotron and Edvon. A front-mounted sensor array reads the track, an Arduino processes the readings, and an L298 motor driver module steers the drive wheels to keep the robot locked onto the line.

  • Arduino-based control with a stacked shield for clean wiring
  • L298 module with heatsink driving the left and right motors
  • Compact blue chassis with a front-mounted sensor bar and ribbon-cable wiring
Arduino L298 Motor Driver Line Sensors C++
Use: Competition-style robot, as seen at events like Robotron and Edvon.

PRJ_10 // DESIGN THINKING

Affinity Diagram: Hospital Emergency Room Study

A design thinking project where my team grouped our observations of a public hospital emergency room into themes with an affinity diagram, then turned them into clear problem statements.

  • Sorted sticky-note observations into two clusters: Registration & Payment Bottlenecks, and Infrastructure & Unhygienic Conditions
  • Wrote Point-of-View statements for a low-income daily wage earner and a stressed patient attendant
  • Framed How-Might-We questions, such as combining token generation and payment into a single counter
Design Thinking Affinity Diagram POV & HMW User Research
Outcome: Turned scattered observations into focused problems worth solving.
